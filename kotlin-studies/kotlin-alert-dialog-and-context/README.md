# Context

App'in (uygulamanın) içinde bulunduğu güncel durumu göstermek için kullanılan yapı

Her objenin - aktivitenin birbiriyle haberleşmesi için, kim ne durumda bilebilmesi için oluşturulmuş yapı

2 Context var.

- Application Context: Uygulamanın genel olarak kendini ilgilendiren işlemler. Bazı durumlarda applicationContext istenir
- Activity Context: Aktivitenin kendisini ilgilendiren işlemler. Bazı durumlarda activity context istenir(this)
