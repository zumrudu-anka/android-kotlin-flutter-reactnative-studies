# 📱 Artbook with Kotlin

## Create a Menu

- Right click on the **res** folder in the android project menu
- Choose **New** -> **Android Resource File** and change **Resource Type** option to **menu**
- Change the menu.xml like what you want
- Go to Activity File and make override two functions
  - **onCreateOptionsMenu** -> Bind menu to activity
  - **onOptionsItemSelected** -> Decide actions when menu item clicked
